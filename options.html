诊断

—

    Manifest V3 下的行为差异

    • 规则由 declarativeNetRequest 直接执行，不再经过扩展进程，因此比旧版更稳，但只能做「URL → URL」重定向。
    • Chrome 不允许扩展把请求重定向到 file://。本地文件请改用本地 HTTP 服务（如 http://127.0.0.1:5500），或把文件放进扩展目录的 local/，规则写成 file:///local/app.js。
    • 不支持 (?=)、(?!)、(?<=) 与反向引用，这类正则在 RE2 引擎下会报错。
    • 同一请求只会被优先级最高的一条规则重定向，旧版「多条规则链式替换」不再生效，请把一条规则写完整。
